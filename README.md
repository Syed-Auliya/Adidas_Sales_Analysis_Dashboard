# 👟 Adidas Sales Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive **Adidas Sales Analysis Dashboard** built using **Microsoft Power BI**. The dashboard provides comprehensive insights into sales performance across different dimensions including time, geography, product categories, retailers, and sales methods.

The goal of this project is to transform raw sales data into meaningful business insights that help stakeholders monitor performance, identify trends, and make data-driven decisions.

---

#  Business Objectives

This dashboard helps answer important business questions such as:

- What is the total revenue generated?
- How much profit has the business earned?
- Which months generated the highest sales?
- Which states contribute the most revenue?
- Which product categories perform the best?
- Which retailers generate the highest sales?
- How does the selected sales method impact performance?
- How do yearly sales compare?

---

# Key Performance Indicators (KPIs)

| KPI | Description |
|------|-------------|
| Revenue | Total sales revenue generated |
| Profit | Total business profit |
| Total Units Sold | Number of products sold |
| Average Unit Price | Average selling price per unit |
| Profit Margin | Percentage of profit earned |

# Dashboard Features

### Executive KPI Cards

Provides an overview of the company's overall performance.

- Revenue
- Profit
- Units Sold
- Average Unit Price
- Profit Margin

---

### Monthly Sales Trend

Analyzes sales performance across all months to identify:

- Seasonal trends
- Peak sales months
- Low-performing periods

---

### State-wise Sales Analysis

Interactive US map showing:

- Revenue by State
- Geographic performance
- Regional comparison

---

### Sales by Region

Displays contribution of each sales region including:

- West
- Northeast
- Southeast
- South
- Midwest
- East

---

### Product Performance

Ranks products based on total sales.

Examples include:

- Men's Street Footwear
- Women's Apparel
- Men's Athletic Footwear
- Women's Street Footwear
- Men's Apparel
- Women's Athletic Footwear

---

### Retailer Performance

Compares sales generated by major retailers including:

- West Gear
- Foot Locker
- Sports Direct
- Kohl's
- Amazon
- Walmart
